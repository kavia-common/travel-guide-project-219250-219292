Simple DB Viewer

This optional tool can list databases and tables and fetch sample rows.

Note: This viewer is not started automatically. Install and run manually: 
cd db_visualizer
npm install
source postgres.env   # optional, or set envs yourself
npm start

API Endpoints

  • GET /api/databases — test connections and list available DBs
  • GET /api/:db/tables — list tables/collections (db = postgres | mysql | sqlite | mongodb)
  • GET /api/:db/tables/:table/data?limit=50 — fetch sample rows/documents
